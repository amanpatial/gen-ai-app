# Science-Inspired IT Company Name Ideas

Names in the spirit of **Cursor**, **Perplexity**, and **Parallel** — rooted in science, math, or tech concepts.

---

| Name | Science link | Vibe |
|------|----------------|------|
| **Helix** | DNA double helix; structure, code, life | Clean, iconic, “building blocks” |
| **Quanta** | Quantum physics; discrete units of energy | Cutting-edge, precise |
| **Tensor** | Math/physics; multi-dimensional data | ML/AI, data, scale |
| **Lattice** | Crystal structure; ordered grid | Systems, networks, order |
| **Flux** | Physics; flow, change over time | Motion, pipelines, streaming |
| **Synapse** | Neuroscience; connection between neurons | AI, connectivity, intelligence |
| **Axiom** | Logic/math; foundational truth | Trust, correctness, core systems |
| **Parallax** | Astronomy; apparent shift from different viewpoints | Perspective, multi-angle analysis |
| **Catalyst** | Chemistry; speeds reaction without being consumed | Acceleration, platforms, enablement |
| **Resonant** | Physics; amplification at matching frequency | Alignment, impact, “hitting the right note” |
| **Lumen** | Unit of light; illumination | Clarity, visibility, insight |
| **Morphism** | Math; structure-preserving map between objects | Transformations, abstractions, APIs |
| **Scalar** | Math/physics; magnitude without direction | Simplicity, one dimension, focus |
| **Vertex** | Math; point where edges meet | Nodes, graphs, connections |
| **Confluence** | Flow meeting; rivers joining | Integration, merging data/workflows |
| **Lemma** | Math; proven step toward a theorem | Building blocks, proofs, reliability |
| **Isotope** | Chemistry; same element, different mass | Variants, versions, branching |
| **Covalent** | Chemistry; shared-electron bond | Collaboration, strong links, partnerships |

## Why these fit the “Cursor / Perplexity / Parallel” vibe

- **Cursor** — Interface, precision, pointing.  
- **Perplexity** — Uncertainty, search, AI.  
- **Parallel** — Concurrency, scale, computing.

The names above tap into:

- **Math/logic** (Tensor, Axiom, Lemma, Vertex, Morphism, Scalar)  
- **Physics** (Quanta, Flux, Parallax, Lumen, Resonant, Entropy)  
- **Chemistry/biology** (Helix, Catalyst, Isotope, Covalent, Synapse)  
- **Systems/flow** (Lattice, Confluence, Flux)

Pick one that matches your product: e.g. **Helix** or **Tensor** for dev/AI tools, **Flux** or **Confluence** for data/platform, **Synapse** for AI/neural, **Axiom** or **Lemma** for correctness and core systems.
